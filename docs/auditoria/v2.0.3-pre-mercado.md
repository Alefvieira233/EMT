## 3. Diferenciadores tecnicos

| # | Diferencial | Por que importa |
|---|---|---|
| 1 | **NBR 6118 nativo** | Calculo de ancoragem + traspasse direto, sem precisar de calculadora externa. Plugins gringos nao falam essa norma. |
| 2 | **Aba dupla EMT/PF** | Fluxo de pre-fabricado fica separado do fluxo geral. Profissional PF nao precisa cruzar com comandos de aço estrutural. |
| 3 | **DSTV/NC1 export** | Compatibilidade direta com maquinas CNC sem precisar pagar Tekla Structures (~US\$ 10-15k/ano por seat). |
| 4 | **Licenciamento offline** | HMAC-SHA256 self-hosted. Sem servidor de auth, sem internet obrigatoria, sem custo recorrente de SaaS. |
| 5 | **Telemetria PostHog HTTP-direct** | Dados de uso REAIS para guiar roadmap. Opt-in com consent versionado. Privacy-by-design. |
| 6 | **Crash reporting Sentry** | Crashes capturados antes do cliente reportar. PII scrubbing automatico. |
| 7 | **Auto-update com 3-attempt fallback** | Atualizacoes em background sem precisar usuario rodar instalador. |
| 8 | **Arquitetura ADR-disciplinada** | 9 ADRs documentando decisoes-chave (003 Result/Progress, 004 Threading, 006 Auto-update, 007 Sentry, 008 PostHog, 009 Code-signing, 010 Legal). |
| 9 | **777 testes unitarios** | Logica pura testada sem precisar abrir Revit. Confianca alta em refactors. |
| 10 | **Culture-invariant em dados intercambiaveis** | DSTV, listas de materiais, parametros — dados que cruzam fronteira de cultura ficam estaveis. |

## 6. Riscos conhecidos

### 6.1 Bus factor 1 — desenvolvedor solo

**Mitigado por:**
- Victor como colaborador 50/50 com snapshots periodicos (`docs/victor/`, `comparacao-victor/`).
- ADRs documentando decisoes-chave (9 ADRs).
- 777 testes automatizados.
- Repo publico — colaboradores externos podem retomar trabalho.

### 6.2 Mercado nicho

**Plugin Revit BR de pre-fabricado/aco** — demanda comprovada (escritorios EMT, Patos, Vulcaflex, Samsung/CRC usaram protocolos similares em projetos reais) mas:
- TQS, Eberick: softwares completos, nao plugins.
- Plugins gringos: nao falam NBR 6118.
- Tekla Structures: ~US\$ 10-15k/ano por seat, fora de alcance pra escritorios BR pequenos.

**Conclusao:** competicao difusa, SteelBIM ocupa nicho especifico (escritorio BR + Revit + PF/aco + budget medio).

### 6.3 Distribuicao manual via GitHub

**Atrito de 1a instalacao:** SmartScreen warning ate ter cert. Mitigado por documentacao clara em `docs/CODE-SIGNING.md` e instrucoes no setup.exe.

## 8. Roteiro de smoke test (Alef executa manualmente — 20 min)

### 8.1 Setup

1. Desinstalar SteelBIM antigo se houver:
   - Painel de Controle → Programas → SteelBIM → Desinstalar
   - OU manualmente: `rmdir /s /q "%AppData%\Autodesk\Revit\Addins\2025\SteelBIM\"`
2. Baixar `SteelBIM-Revit2025-Setup.exe` da release v2.0.3.
3. Executar setup. Aceitar SmartScreen ("Mais informacoes" → "Executar assim mesmo").
4. Abrir Revit 2025.

### 8.2 Validacao da versao

5. Aba "SteelBIM" no ribbon → painel "Licença" → comando "Sobre". **Verificar: versao mostra `2.0.3`**.
6. Aba "Ferramentas ECC" no ribbon → painel "Licença" → comando "Sobre". **Verificar: versao tambem `2.0.3`**.

### 8.3 Smoke test funcional (modelo com vigas/pilares + 1+ diagonal)

7. **Nomear PF** (regression v2.0.1 + v2.0.2):
   - Abrir comando, escolher `Vigas`, escopo `Vista Ativa`.
   - **Verificar cabecalho** na lista filtrada: `[N elemento(s) — lista por familia/tipo para filtro; a ordem de numeracao e geometrica]`.
   - Aplicar. Verificar dialogo final.
   - Em modelo com vigas diagonais: dialogo menciona `"X viga(s) sem eixo definido foram numeradas por Id ao final da sequencia"`.
   - Selecionar 2 vigas adjacentes no mesmo eixo logico (~10cm desalinhadas): devem ter numeros consecutivos.

8. **Cortar Elementos** (regression v1.8.0):
   - Abrir comando.
   - Janela aparece com radios `Selecao` / `Vista Ativa` / `Modelo` + filtros de categoria.
   - Aplicar em 2-3 elementos. Verificar que nao crasha.

9. **Marcar Peças** (smoke geral):
   - Selecionar 3-5 vigas do mesmo tipo.
   - Executar Marcar Peças.
   - Confirmar marcas geradas e visiveis no Properties Browser.

10. **Sobre + Licenca** (smoke comercial):
    - Comando "Sobre" exibe `v2.0.3`, machine ID.
    - Comando "Ativar Licenca" abre janela sem crashar.

### 8.4 Resultado esperado

Se TODOS os 10 itens passam: **plugin esta pronto para apresentacao publica**.
Sinaliza no chat e pode comecar a pagina de vendas.

Se algum falha: reporte qual item + screenshot do erro/dialog.
